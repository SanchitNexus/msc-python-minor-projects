# M.Sc. Informatics - 10 Minor Python Projects

This repository contains 10 beginner-friendly minor projects developed in Python for academic practical assignments and viva voce demonstrations.

---

## Project Overview

| # | Project Name | Type | Description | Script |
|---|---|---|---|---|
| 1 | **Country Information Finder** | API | Fetches live country details (Capital, ISO code) using the CountriesNow REST API | `project_01_country_info.py` |
| 2 | **Random Joke Generator** | API | Fetches random jokes using the Official Joke API | `project_02_joke_generator.py` |
| 3 | **Student Grade Calculator** | Offline | Calculates total, percentage, and assigns grades (A+, A, B, C, F) | `project_03_grade_calculator.py` |
| 4 | **Simple Expense Calculator** | Offline | Records category expenses and finds total spend and highest expense | `project_04_expense_calculator.py` |
| 5 | **Electricity Bill Calculator** | Offline | Computes tiered slab power bills with fixed meter maintenance fees | `project_05_electricity_bill.py` |
| 6 | **Password Strength Checker** | Offline | Evaluates length, digits, and uppercase characters | `project_06_password_checker.py` |
| 7 | **Student Attendance Calculator** | Offline | Checks attendance percentage and university 75% exam eligibility | `project_07_attendance_calculator.py` |
| 8 | **Simple Quiz Application** | Offline | Interactive console quiz with normalized answer verification | `project_08_quiz_app.py` |
| 9 | **Temperature Converter** | Offline | Converts temperatures between Celsius and Fahrenheit | `project_09_temperature_converter.py` |
| 10 | **To-Do List Manager** | Offline | Interactive menu-driven console task organizer | `project_10_todo_manager.py` |

---

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SanchitNexus/msc-python-minor-projects.git
   cd msc-python-minor-projects
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run any project:**
   ```bash
   python project_01_country_info.py
   ```
